# The POSIX path wrappers of the Windows build (compat/win32/paths.c), which
# compat/win32/include/x11compat-win32.h binds fopen, stat, opendir, ... to in

# (compat/win32/imports.c), which dlopen() looks up by name. libX11-compat
# exports them so any program or library that links it (the toolkits, the
# examples, Open Inventor) resolves them from one implementation. Windows
